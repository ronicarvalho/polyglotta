# NAudio — referência

Documentação do NAudio pode ser consultada através do link: https://github.com/naudio/NAudio/blob/main/README.md

O projeto usa **NAudio 3.x** (ADR-0005). Guia oficial de migração 2.x → 3.x, com todas as quebras: https://github.com/naudio/NAudio/blob/main/Docs/MigratingFromNAudio2.md

A documentação XML dos pacotes (`~/.nuget/packages/naudio.wasapi/3.1.0/lib/net9.0/NAudio.Wasapi.xml` e `naudio.core/...`) é a referência mais confiável para assinaturas.
